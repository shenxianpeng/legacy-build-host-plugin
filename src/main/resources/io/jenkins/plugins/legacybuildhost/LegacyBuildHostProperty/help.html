Turns this agent into the proxy of a build host that cannot run a Jenkins agent, for example AIX 7.1 or RHEL/CentOS 6, where no supported Java version is available.

Every process Jenkins starts on this agent, including Pipeline sh steps, runs on the legacy host over SSH, in the same directory. File operations such as junit, archiveArtifacts or readFile keep running on this agent.

The workspace directory under this agent's remote root directory must be shared with the legacy host at the same path, for example over NFS, with the same user id on both machines. When the agent comes online, its log shows whether the legacy host sees that directory.
